Publish with GitHub Pages
1. Sign in to GitHub and create a new repository, for example: gentlesmile-dental-ct
2. Set the repository to Public (or use a plan that supports Pages for private repositories).
3. Upload index.html to the repository's root folder. You can also upload this README if you want.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”.
6. Select branch “main” and folder “/ (root)”, then click Save.
7. Wait for GitHub to publish the site. The URL will look like https://YOUR-USERNAME.github.io/gentlesmile-dental-ct/.

Before publishing
- Verify the business phone and address are correct.
- The supplied Google Business Profile screenshot says “Open 24 hours”; the page labels this as the Google listing and advises visitors to call to confirm availability.
- Confirm the clinic's actual services, hours, and any credentials before adding stronger claims. Service cards are intentionally worded as general contact prompts, not guarantees of specific treatment availability.
- This website does not automatically connect to or edit the Google Business Profile. Add the final published URL to the website field in the profile after testing it.

To use a custom domain
In Settings → Pages, enter your domain and follow GitHub's DNS instructions. Use HTTPS once it becomes available.
